Operational Schedule

Stage 1Final technical testing: Complete all test-plan scenarios using G077, G081 and one temporary test guest. Correct all failures before release.
Stage 2Guest-list freeze: Validate names, mobile numbers, household grouping and expected guest counts. Remove duplicate or obsolete records.
Stage 3Initial invitation issue: Send personalised WhatsApp invitations in controlled batches. Mark each invitation sent immediately after sending.
Stage 4First reconciliation: Review delivery issues, incorrect numbers and early responses. Manually capture telephone confirmations or declines.
5 AugustDaily reminder 1: Send reminders only to guests still marked Pending and record each reminder in the tracker.
6 AugustFinal deadline reminder: Contact all remaining Pending guests before 10:00, then lock the confirmed guest count for catering.
Stage 7Event-day control: Use the Admin portal for final guest lookup and optional check-in recording. Export a final backup before the event.
